# JHCIS Backup Master

ระบบสำรองข้อมูลฐานข้อมูล JHCIS อัตโนมัติ สำหรับสถานีอนามัย/รพ.สต. ในสังกัดสำนักงานสาธารณสุขอำเภอเมืองสตูล

## คุณสมบัติเด่น

- สำรองข้อมูลฐานข้อมูล MySQL (JHCIS) อัตโนมัติ ตามวันและเวลาที่กำหนด
- เข้ารหัสไฟล์สำรอง AES-256 และบีบอัดเป็น .zip ประหยัดพื้นที่ฮาร์ดดิสก์
- ซิงค์ไฟล์สำรองขึ้น Google Drive อัตโนมัติหลัง Backup เสร็จ
- ซิงค์ไฟล์สำรองลง Flash Drive / External HDD ด้วยปุ่มคลิกเดียว
- รายงานสถานะการสำรองข้อมูลไปยัง Dashboard ศูนย์กลาง (สสอ.) แบบ Real-time
- ลบไฟล์สำรองเก่าเกินกำหนดทิ้งอัตโนมัติ ทั้งในเครื่องและบนคลาวด์
- กู้คืนข้อมูล (Restore) ง่ายเพียงคลิกเดียว
- อัปเดตโปรแกรมอัตโนมัติผ่าน GitHub พร้อมระบบตรวจสอบลายเซ็นดิจิทัล
- ทำงานแบบซ่อนตัวเบื้องหลัง (System Tray) ไม่รบกวนการทำงานของเจ้าหน้าที่
